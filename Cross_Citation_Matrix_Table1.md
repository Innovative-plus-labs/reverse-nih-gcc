## Interpretation

The three literatures describe the **same phenomenon** — systematic foreign preference in GCC — using three **completely disconnected vocabularies**:

| Cluster | Vocabulary | Key concept |
|---------|-----------|-------------|
| A — NIH/buy-in | "not invented here," "buy-in syndrome," "external knowledge attitudes" | Attitudinal bias toward external |
| B — GCC HR | "labor market segmentation," "nationalization," "ghost employment," "expatriate preference" | Institutional foreign preference |
| C — GCC procurement | "shadow players," "consulting lock-in," "reform failure," "Expatriation 2.0" | Foreign consultant dependency |

**Our paper's contribution (Table 1 evidence):**
1. All 6 inter-cluster cells = functionally 0
2. These three literatures describe the SAME underlying phenomenon without ever citing each other
3. Our paper is the FIRST to integrate them under the buy-in syndrome / Reverse NIH construct
4. Adding gatekeeping theory provides the mechanism layer missing from all three

## Note on Methodology

Cross-citation analysis was conducted programmatically via OpenAlex API cross-citation queries. All three clusters were queried for mutual references. Results confirmed the zero-citation finding reported in the paper draft (Section 2, SLR Methodology).
